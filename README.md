# Lumea Engine Packages

This directory contains the shared packages and libraries used across the `lumea-engine` monorepo. 

## Packages

- `db`: Database schema, migrations, and client for Lumea Engine.
- `types`: Shared TypeScript type definitions and interfaces used across various applications (e.g., worker, web) within the project.

These packages are meant to be imported and used by the applications in the `apps/` directory to share code and ensure consistency.
